# ESP32 Projects Collection

A collection of practical IoT and embedded systems projects built with the ESP32 microcontroller.

## Project Index

- [Smart Traffic Light System](./smart_traffic_light/README.md) - Ultrasonic sensor-based intelligent traffic control

## Overview

This repository includes projects focused on sensor integration, real-time processing, and automation. Each project folder contains a dedicated README with circuit diagrams, wiring information, pin configurations, and detailed explanations.


## Getting Started

1. Open the project folder you want to explore.
2. Read that project's README for wiring and setup details.
3. Install Arduino IDE and ESP32 board support.
4. Upload the sketch to your ESP32 board.
5. Connect components according to the circuit diagram.
